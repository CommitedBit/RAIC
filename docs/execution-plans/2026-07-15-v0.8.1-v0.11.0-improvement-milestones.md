# Execution Plan: v0.8.1-v0.11.0 Improvement Milestones

Date: 2026-07-15

## Operating Contract

- Start every slice from current `origin/main` in a clean non-iCloud checkout under Node 24.
- Keep changes serial and single-purpose; merge and revalidate each release before starting the next.
- Keep AGPL-3.0, the current package layout, provider governance, and disabled production capabilities unchanged unless a milestone explicitly says otherwise.
- Treat roadmap documents and release evidence as the project tracker. Do not infer completion from local code or a nominal smoke command.

## v0.8.1 Dependency Security

- Upgrade direct vulnerable packages to patched lines and resolve transitive alerts through compatible parent upgrades first.
- Permit a `pnpm` override only when no compatible parent release resolves an advisory; document its owner and removal condition.
- Add a low-threshold dependency audit to local release gates, CI, and a weekly scheduled workflow.
- Exit only with zero open Dependabot alerts, frozen-install proof, complete Node 24 gates, preview proof, and production health proof.
- Make no public request, response, persistence, or capability changes.

## v0.9.0 Governed PDF Source Foundation

- Normalize existing PDF providers behind internal document artifact, block, asset, citation, and diagnostic types.
- Add teacher-authenticated private Blob client uploads with a server-issued pathname and a separate private source store.
- Enforce PDF-only input, 50 MB client uploads, 4 MB legacy multipart requests, 200 pages, 200,000 extracted characters, 50,000 generation characters, and a 240-second extraction timeout.
- Verify content type and PDF signature, omit raw provider output and inline asset data from serialized artifacts, and sanitize logs and failures.
- Delete consumed raw files immediately and remove abandoned uploads after one hour.
- Keep `/api/parse-pdf` backward-compatible, add truthful `sourceDocumentsV2` health reporting, and keep the new path disabled when private storage is unavailable.

## v0.10.0 Source-Grounded Authoring

- Accept optional `sourceDocuments` generation input while retaining legacy `pdfContent`; enforce one PDF initially.
- Let teachers inspect and select pages. Fill the 50,000-character context budget with selected pages first, then remaining pages in document order.
- Persist only document summaries, citation references, and at most 500 characters per used citation.
- Strip excerpts and original filenames from public and student responses.
- Validate citation IDs, reject invented references, and preserve the existing source-required failure for empty or unusable extraction.
- Add teacher-only citation badges and a source inspector without a database migration.

## v0.11.0 Governed Edit with AI

- Gate the feature behind default-off `RAIC_EDIT_WITH_AI` and require teacher authorization.
- Generate structured patches only for selected slide elements: text replacement, safe style changes, move/resize, text or shape creation, removal, and slide background changes.
- Reject arbitrary HTML, scripts, external URLs, image replacement, actions, interactive scenes, deck-wide edits, stale scene hashes, and unknown element or citation IDs.
- Preview patches before applying them atomically through the stage API and record one undo snapshot.
- Enable production only after signed-in edit/apply/undo proof; flag disablement is the rollback.

## Release Evidence

- Run secrets, dependency audit, drift, i18n, TypeScript, formatting, lint, unit, build, MiroFish contract/E2E, full Playwright, milestone benchmark, and `ops:verify` for every tag.
- Prove `v0.9.0` with a synthetic PDF larger than 4.5 MB in a protected preview and verify no raw Blob remains.
- Use disposable fake data with cleanup for preview source and edit smokes. Keep production mutations explicitly manual until dedicated smoke credentials and cleanup are approved.
- Record the production alias, deployment identifier, `/api/health`, capability truth, rollback target, and relevant classroom smoke before publishing each GitHub release.

## Deferred Work

- Persistent source libraries, DOCX/PPTX/text/Markdown ingestion, PBL v2, and the `@openmaic/*` package split remain separate decisions.
- Student adaptation remains disabled pending approved consent, retention, deletion, leakage, and rollback requirements.
